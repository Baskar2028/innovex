# INNOVEX 2K26 🚀

> **National Level Technical Symposium**

The official website for **INNOVEX 2K26**, a National Level Technical Symposium featuring technical, competitive, and creative events.

The platform is designed to provide participants with event information, symposium details, schedules, rules, and other important announcements through a modern and responsive web interface.

## 🌐 Live Website

**https://innovex.onrender.com**

## ✨ Features

* 🎯 Symposium information
* 🎪 Event details and rules
* 📅 Event schedules
* 🏆 Competition information
* 👨‍💻 Technical event details
* 🎨 Creative event information
* 📱 Responsive design
* ⚡ Fast and lightweight frontend
* 🚀 Production deployment on Render

## 🚀 Deployment

The website is deployed as a **Node.js Web Service on Render**.

The production flow is:

```text id="8v8d5f"
GitHub
   │
   ▼
Render
   │
   ├── React + Vite Frontend
   │
   └── Express.js Server
            │
            ▼
       Live Website
```
